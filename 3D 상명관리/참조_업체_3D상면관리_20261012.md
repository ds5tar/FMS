## 2. 공통으로 갖춘 것 (FMS 에 꼭 넣을 것)
1. 3D 와 2D 평면을 같이 둔다 — 3D 는 보기, 2D 는 편집이 쉽다.
2. 색 기준을 바꿔 칠한다 — 알람 / 공간 점유율 / 전력 사용률 / 온도.
3. 랙을 누르면 랙 입면(U 단위 실장도)과 장비 상세가 나온다.
4. 랙 용량은 공간(U)·전력(kW)·발열(냉각)·중량을 함께 본다.
5. 편집기 — 평면에 랙·항온항습기·기둥·벽을 놓고 옮기고, 랙 안에 장비를 U 위치로 넣는다.
6. 빈 자리 찾기 — 「nU·nkW 장비를 넣을 랙」 을 찾아 준다 (Sunbird·Schneider).

## 3. FMS 가 이미 가진 것과 차이
- 센서·알람·예측은 FMS 가 강하다. 업체 제품의 「실시간 측정값」 칸을 FMS 센서(온습도·랙 PDU 전력)로 채울 수 있다.
- FMS 에 없는 것 — 랙·U 실장 자산 표, 랙 용량(정격 kW·중량), 평면 편집기, 3D 보기.
- 기존 `C:\claude\FMS\room3d.html` (외부 의존 0건 캔버스 3D, 랙 291·항온항습기 28) 을 출발점으로 쓸 수 있다. 폐쇄망 규칙상 Three.js CDN 은 못 쓴다.

## 4. 이번에 넣지 않을 것 (업체 고급 기능)
- 포트·케이블 연결도, 작업 지시서·승인 워크플로, 기류(CFD) 시뮬레이션, 모델 1만 개 라이브러리.
